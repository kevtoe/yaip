# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for a vulnerability or possible credential exposure.

Include the affected version, reproduction steps, impact and any suggested fix.
You should receive an acknowledgement within seven days.

## Scope

Security reports are especially useful for issues involving microphone access,
Accessibility permissions, text insertion, local history, model downloads,
archive handling, code signing or release verification.
